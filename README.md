Приложение для автоматической проверки компрометации учётных записей сотрудников на основе двух журналов:

* **Журнал входов на ПК**
* **Журнал входа/выхода с территории**

Программа анализирует данные, сопоставляет сотрудников из двух источников и определяет:

* **Утечки** — пользователь входил в систему, но отсутствует в журнале проходной
* **Нет входа** — сотрудник есть в проходной, но не входил на ПК
* **Сопоставлено** — пользователь найден в обеих таблицах

# Логика проверки

После загрузки файлов приложение:

1. Ищет строку заголовка в каждом файле
2. Парсит строки в словари
3. Группирует записи логинов и проходной по имени (`User Display Name` и `ФИО`)
4. Формирует три списка:

### **1. Утечки**

Пользователь есть в логинах, но отсутствует среди входивших на территорию.

### **2. Сопоставлено**

Пользователь найден и там, и там.

### **3. Нет входа**

Пользователь входил на территорию, но не логинился в систему.

# Экспорт результатов

При нажатии кнопки "Экспорт" создаётся Excel-файл.
В нём:

### Лист 1 — *Утечки*

### Лист 2 — *Нет совпадений*

### Лист 3 — *Сопоставлено*

На каждом листе:

* заголовки объединённых полей
* строки содержат данные **из обеих таблиц**
* ширина столбцов подгоняется под длину текста
* Русские имена и формат дат сохраняются корректно
